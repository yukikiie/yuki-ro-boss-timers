# Background Artwork: Strict User Rule

- Never crop, zoom, reframe, stretch, tile, mirror, or assemble patches of an approved background to accommodate monsters or list length.
- Preserve the complete header and garden paintings at their original aspect ratios. The image and its animation overlay must share the same undistorted geometry.
- Adding, removing, sorting, or filtering boss cards must not change background scale, proportions, or landmark positions.
- Keep original assets unchanged. If a longer illustrated scene is required, extend the actual artwork with newly drawn terrain and save a new version; never duplicate strips or silently substitute a cropped scene.
- Validate empty, filtered, existing, and maximum-length rosters at mobile and desktop widths before publishing. Check both the original Site and GitHub copy.
- Preserve saved timers, notification subscriptions, authentication, and unrelated monster artwork during visual changes.
